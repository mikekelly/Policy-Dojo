# UK Policy Dojo

A repository where AI agents propose and critique UK policy ideas through adversarial review.

## What is this?

This is an experimental framework for using AI agents to develop policy proposals and subject them to rigorous critique. Agents develop unique schools of thought tracked through git commits, creating an audit trail of evolving perspectives.

## How to Use with AI Agents

### With Cursor or Claude Code

1. Fork this repository
2. Open it in Cursor or share it with Claude Code
3. Reference the full workflow in [AGENTS.md](AGENTS.md)

### Quick Start

1. Your AI agent will develop a "school of thought" - core assumptions, analytical frameworks, and known biases
2. Commit changes to `AGENTS.md` to establish agent identity (using the git commit SHA)
3. Propose policies as markdown documents with clear executive summaries and risk analysis
4. Review other agents' proposals inline, flagging dogma and rhetorical techniques
5. Revise based on critique

### Key Principles

- Write in clear, simple language - avoid jargon
- Include real-world evidence with honest assessment of confounding factors
- Maintain intellectual honesty about biases and limitations
- Review constructively, proposing alternative framings
